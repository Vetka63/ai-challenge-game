# Источники и лицензии ассетов

Текущие цветные герои и кадры анимации созданы встроенным `image_gen`;
происхождение и запросы находятся в `art/sprites/hero-animations/`
и описаны в `digital-world.md` и `hero-animations.md`. Искра — собственный
персонаж; Pac-Man и Doomguy — фанатские варианты для личного прототипа,
а не оригинальные персонажи проекта и не лицензированный коммерческий набор.
Исходные изображения из игр Pac-Man и Doom в проект не импортировались.
Сторонние скриншоты референса и коллаж с ними исключены из Git.

Текущий выбранный вариант A: `TerminalActorArt.cs` и `TerminalGlyphBatch.cs`.
Матрицы — собственные; глифы мира и HUD — JetBrains Mono Medium, SIL OFL 1.1.
Источник: https://github.com/JetBrains/JetBrainsMono . TTF и лицензия сохранены
в `Assets/StyleStudy/Fonts`, рабочий статический SDF-атлас —
`Assets/Prototype/Art/Terminal/TerminalMono.asset`. Лицензия включена в StyleA.
Шрифт уже использовался в согласованной пробе A; новые пакеты не устанавливались.
Кадры Steam используются только в исследовательском сравнении, не в игровой сцене.
Короткие звуки ArenaAudio сохранены без изменений.

Предыдущий вариант: `art/sprites/ascii-actors-v4-hover` и Unity `Art/HoverActors`.
Это собственные ASCII-матрицы персонажей в плащах без ног, экспортированные
через собственный GlyphAtlas: 24 PNG, 128×128. ЭЛТ-шейдер PhosphorCRT написан
для этого проекта; использует стандартные include и FullScreenPassRendererFeature
из установленного URP. Новые сторонние изображения, шрифты и пакеты не добавлялись.

В ASCII-прототипе используется собственная символьная графика и ресурсы
TextMeshPro из Unity uGUI. Платные наборы Synty не импортированы.

В `art/concepts/ascii-survivors-v2/` сохранены созданные через встроенный
`image_gen` эскизы персонажей и боя для нового направления. Рядом находятся
полные запросы и `provenance.json`. Это концепты вне Unity Assets;
изображения и модели чужой игры не импортировались.

В `art/concepts/sprite-skill-ab/` находятся восемь дополнительных концептов
для сравнения обычного ImageGen и этапа подготовки master still из Sprite
Forge. Исходные PNG не редактировались. Полные запросы, manifest, измерения
и MIT-лицензия шаблона Sprite Forge сохранены рядом. Это эскизы вне Unity,
а не готовые игровые спрайты или проверенные анимации.

## Ресурсы прототипа

Предыдущий runtime использовал оригинальные ASCII-матрицы из `AsciiActorArt.cs`
и собственный шрифт `GlyphAtlas.cs`: четыре направления/ходьба героя, три
противника и босс. PNG-экспорт (24 файла) — `Assets/Art/AsciiActors/`, копия
для просмотра — `art/sprites/ascii-actors-v3/`. Экспорт выполняется Editor API
из тех же данных. Это программная композиция ASCII, не новая генерация ImageGen.
Короткие звуки синтезируются `ArenaAudio.cs`, внешние аудиофайлы не добавлялись.

15 октября 2026 из собственного девяти-персонажного концепта выбраны №1
Runescribe и №7 Hex Cultist. В `art/sprites/roster-01-07-v1/` сохранены
master still, исходные листы ImageGen, запросы, исправления, обработка
Sprite Forge 0.4.0 и готовый набор 128 кадров/24 клипов. Источники и границы
проверки описаны в README набора; точная модель и стоимость не сообщены
инструментом. Анимация покадровая, видеосервис не использовался. Рисунки других
игр не импортировались. Unity API создал соответствующие импортированные
ассеты и `.meta` в `AsciiArena/Assets/Art/Roster0107/`.

Набор подготовлен для оценки в игре; вариативность мелких деталей и
замечания к движению отражены в QA. Общая лицензия проекта не назначена.

## Рассматриваемый источник Synty

Synty рассматривается для изометрической экстракшен игры; паки не приобретались
и не импортировались в рамках этой задачи. Сведения о POLYGON Heist, Apocalypse
и Dungeon, примеры игр и условия распространения сохранены в
[записке по Synty](research/synty-isometric-extraction.md).

Synty не утверждён как исключение из требования свободного распространения
исходных ассетов. Записка описывает кандидата и не заменяет реестр лицензий
конкретных добавленных файлов.

## Проверка перед добавлением

15 октября создан [один ASCII-спрайт Runescribe](../art/sprites/runescribe-ascii-v2/README.md).
Он собран из оригинальной матрицы 49 ASCII-знаков и собственного GlyphAtlas.cs,
сохранён как PNG вместе с текстом и картой глифов. Ассеты ASCII Survivors
не копировались. Предварительная генерация ImageGen не является итоговым
спрайтом и сохранена отдельно для происхождения. Шрифт Consolas использован
лишь для подписей сравнительного PNG; файл шрифта не включён в набор.

Перед добавлением каждого набора фиксируем:

- название и автора;
- URL оригинального источника и версию/дату загрузки;
- текст лицензии;
- возможность распространять исходные ассеты в публичном репозитории;
- требования атрибуции и сделанные изменения.

Бесплатная загрузка не означает разрешение на перепубликацию файлов.
Собственную лицензию проекта выберем отдельно. Не добавляем материалы
с неясным происхождением или доступные только по закрытой ссылке.
