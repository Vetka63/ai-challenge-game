# Runescribe 01 и Hex Cultist 07 — игровые спрайты v1

15 октября 2026. Сделаны по персонажам №1 и №7 собственного исходного листа
`../../concepts/ascii-survivors-v2/roster-concept.png`. Пользователь выбрал
четыре направления движения. Это отдельный набор ассетов для Unity;
он ещё не заменяет графику сцены Arena.

## Состав

- Два героя: бирюзовый Писец рун с посохом и пурпурный Культист с пустыми руками.
- Для каждого: south, north, west, east; idle, walk, cast.
- 128 отдельных RGBA PNG; 24 полосы кадров; два атласа 1024×1024.
- Кадр 128×128; высота нейтральной фигуры около 72 px. Поля оставлены для посоха.
- Общая палитра 32 цвета, бинарная прозрачность, без dithering.
- Общая опора: (64,108) от верхнего левого угла PNG;
  Unity pivot (64,20), normalized (0.5,0.15625), 64 PPU.

| Действие | Кадры | Время | Повтор |
| --- | --- | --- | --- |
| idle | 4 | 200 ms/кадр, 800 ms | да |
| walk | 6 | 100 ms/кадр, 600 ms | да |
| cast | 6 | 100,100,100,100,100,200 ms; 700 ms | нет |

`cast` содержит подготовку, выпуск заклинания, отдачу и возврат.
Событие `custom:spell_release` в JSON наступает на 300 ms. VFX, снаряд и урон
должны запускаться игровыми системами. В `.anim` нет обязательных вызовов
MonoBehaviour: готовые prefab не вызывают несуществующие обработчики.

## Использование

`Roster0107.unitypackage` импортируется через Assets → Import Package → Custom Package.
В текущем проекте ассеты уже находятся в `AsciiArena/Assets/Art/Roster0107/`:
два prefab, два Animator Controller, 24 AnimationClip, материалы URP 2D Unlit
и два нарезанных атласа. Texture settings: Point, no mipmaps, Uncompressed.

Prefab по умолчанию проигрывает `idle_south`. Контроллеры содержат именованные
состояния без переходов: выбор состояния принадлежит представлению игры.
Например, вызвать `animator.Play("walk_west", 0, 0f)` при смене состояния;
не вызывать Play с нулевым временем каждый Update. После завершения cast
представление выбирает idle/walk по данным ECS. Для толпы можно читать
PNG-атлас и JSON напрямую, не создавать Animator на каждую сущность.

PNG и метаданные находятся в `runtime/`; WebP по действиям — в `clips-v2/`.
`previews/walk.gif`, `idle.gif`, `cast.gif` показывают оба героя во всех ракурсах
с увеличением ×2. Cast в общем превью повторяется с паузой для просмотра;
сам игровой клип остаётся однократным.

## Происхождение и воспроизведение

Art source: `host_image`, встроенный `image_gen`. Использованы собственный
концепт и два master still из `masters/`. Точное имя модели и стоимость
инструмент не сообщает; они сохранены как null, а не угаданы.
`sources.json`, `corrections.json`, `walk-corrections.json` и `raw/*-prompt.txt`
фиксируют запросы и последовательность исправлений. Последние два manifest
имеют приоритет над первоначальным sources. `rejected/` хранит заменённые дубли.

Обработка: Sprite Forge `generate2dsprite` 0.4.0,
commit `5324342fdfab72430f4e9604f3fe427009f8596d`.
Доступного image-to-video маршрута здесь нет. Применена покадровая генерация
листов; это отклонение от основного видеопроцесса skill, а не его проверка.
Python использован для технической нарезки, регистрации, палитры и упаковки;
позы и рисунок созданы ImageGen. Анимации не являются процедурным качанием
одного статичного изображения.

`process_assets.py` выполняет проверки исходных листов и нарезку.
`package_assets.py` выравнивает корпус и опору, применяет одну палитру,
собирает клипы и превью. Один масштаб применяется ко всему действию;
разная исходная плотность листов нормализуется по нейтральной позе.
Покадрового изменения масштаба тела нет.
`import-unity.cs` и `verify-unity.cs` — блоки для Unity Pipeline `eval_file`,
они лежат вне Assets и не входят в игру. `.meta`, `.anim`, `.controller`,
`.mat` и `.prefab` создаются Unity Editor API.

## Проверки и ограничения качества

`runtime-validation.json` проверяет количество/размер кадров, палитру,
прозрачность и отсутствие обрезания. `unity-validation.json` проверяет
выборку всех 128 кадров в AnimationClip, длительности, loop, pivot и настройки
текстур. Unity работал с `graphicsDevice=Null`; проверка GPU-отрисовки
и Play Mode сцены Arena в эту проверку не входят.

Художественные эвристики Sprite Forge дополнительно оценивают форму капюшона,
дрейф корпуса, повторение поз и чередование ног. Их WARN/FAIL сохранены
дословно с числами и порогами в `QA-DETAILS.md` и `qa-issues.json`, включая
отклонённые исходники. Этот пакет не заявляет «все художественные проверки
пройдены». Длинные мантии скрывают ноги, а верхушка посоха влияет на оценку
головы. Кроме ограничений распознавания, остаётся реальная вариативность
мелких рун и контуров между кадрами. Для окончательного коммерческого арта
понадобится художественная полировка; текущие файлы можно импортировать и
использовать для оценки движения и читаемости в игре.

Исходники ASCII Survivors, Synty или других игр в набор не входят.
Общая лицензия проекта этим набором не назначается.
