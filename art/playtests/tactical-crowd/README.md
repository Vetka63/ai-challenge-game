# Проверка обычных врагов и ускорения

16.10.2026. Сборка `AsciiArena/Builds/TacticalCrowd/AsciiArena.exe`.

- `editmode-tests.json`: 60/60. Новые проверки: фиксированная траектория
  рывка, уход в сторону, попадание по пройденному отрезку, препятствие;
  фиксированная зона взрыва, выход и отмена убийством; обход и три снаряда;
  лимит предупреждений и запрет старта вне экрана; постепенное появление
  ролей и пределы количества; одинаковый бой при x1/x2/x4, пауза без скачка;
  состояние новых врагов после загрузки, чтение v1, сохранение настройки скорости.
- `build.json`: финальная инкрементальная сборка, 0 ошибок, 1 предупреждение
  о неиспользуемом RuntimePipelineConfig. `build-initial.json` хранит первую
  полную сборку с 69 предупреждениями, в основном о тестовых ресурсах Extenject.
  Инкрементальная сборка не считается исправлением предупреждений зависимости.
- `final-720p` / `final-1080p`: реальные D3D11-кадры и `tactics-check.json`.
  Проверяются кнопка меню скорости x1 → x2 → x4 → x1, измеренное отношение
  игрового и реального времени, пауза на x4, возобновление сохранённой толпы.
- `720p` / `1080p`: предыдущие успешные прогоны до добавления тёмной подложки
  подсказки. На них обнаружено наложение текста на фигуры у верхнего края.
- `tactical-crowd.gif`: 32 GPU-кадра финальной 720p-сборки с временными
  интервалами из отчёта; собирается `tools/create-tactics-preview.py`.

В сцене проверки 44 врага, включая по одному новому специалисту. Размещение
контролируется диагностикой: оно проверяет предупреждения и слои в толпе,
не доказывает баланс обычного 30-минутного забега. На этих кадрах урон
автоатаки героя отключён, чтобы сохранить фигуры для сравнения. Production-
настройки asset не изменены; сохранения теста изолированы через `--act-save-dir`.

Диагностика запускается только по `--tactics-capture <output>` в development
Player. Editor и Players запускались с двумя рабочими потоками; Players
последовательно. Звук отключён через `-noaudio`, его проверка не заявляется.
При закрытии сохраняется прежнее предупреждение Unity о ComputeBuffer;
оно не считается исправленным и отдельно видно в логах.
