# AI Challenge Game

Отдельный учебный проект 2D-игры на Unity и C# с двумя законченными уровнями.

## Текущее состояние

Подготовлен только Git-репозиторий и контекст для проектирования. Unity-проект,
игровой код, сцены, пакеты и ассеты ещё не созданы. Репозиторий пока нельзя
открыть как готовый проект в Unity Hub. Концепция и версия Unity не утверждены.

Сначала согласуем игру, платформы, механики и архитектуру. Реализация начнётся
только по отдельной команде пользователя.

## Связанный проект

[AI Challenge Code Assistants](https://github.com/Vetka63/ai-challenge-code-assistants)
будет отдельным ассистентом разработчика с RAG, MCP и автоматическим PR-ревью.
Игра должна работать самостоятельно, без LLM и подключения к ассистенту.

## Git и безопасность

Основная ветка — `main`. Unity-кеши, сборки, локальные настройки и секреты
исключены из Git. Файлы `.meta` версионируются вместе с соответствующими
ассетами после создания проекта через Unity.

Git LFS настроен для исходников графики и крупных бинарных форматов. Небольшие
PNG остаются обычными Git-файлами. Сейчас LFS-объектов нет.

Публичная видимость репозитория сама по себе не задаёт лицензию его кода.
Лицензию проекта выберем отдельно; права на сторонние ассеты проверяются
перед добавлением.
